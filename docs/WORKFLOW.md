## DEPLOY process

1. Create a new branch

```bash
git checkout -b [type]/[brief-description]
```

2. Work

- Just work the way you usually do, save with CTRL + S

3. AC"P"

```bash
git add .
```

```bash
git commit -m "..."
```

4. P(ush)

```bash
git push origin [type]/[brief-description]
```

5. MR/PR

- Approve it on GitHub and merge it

6. U2D (aka Up to date)

```bash
git checkout master
```

```bash
git pull
```
